# Você Cairia? — Simulação de Phishing

Projeto educacional de Segurança da Informação do IFRO Campus Ariquemes.

## Tema da simulação

A interface foi adaptada para a temática de um cursinho preparatório gratuito para o ENEM. A proposta investiga como a familiaridade com ofertas de estudo, a gratuidade e a promessa de benefício acadêmico podem influenciar a credibilidade de uma oferta simulada.

## Estrutura

- `index.html` — página inicial/oferta
- `login.html` — inscrição fictícia
- `resultado.html` — revelação e conteúdo educativo
- `style.css` — identidade visual e responsividade
- `imgs/` — imagens do projeto

## Segurança

A inscrição é apenas demonstrativa. Os valores digitados no formulário não são lidos, armazenados, transmitidos ou usados para autenticação.

A pesquisa exibida na página final também é apenas local: as respostas não são enviadas nem armazenadas pelo site.
